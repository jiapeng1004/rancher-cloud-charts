========================================
 charts/supabase（默认内嵌 Postgres · Kong）
========================================
{{- $name := default .Chart.Name .Values.nameOverride | trunc 63 | trimSuffix "-" }}
{{- $fullname := .Values.fullnameOverride | default (printf "%s-%s" .Release.Name $name) | trunc 63 | trimSuffix "-" }}

与上游 docker-compose 取向一致：默认 **内嵌 PostgreSQL 子 chart**（`postgresql.image` 宜为 **supabase/postgres**）
与 **Kong**（`gateway.mode=kong`）。生产可走 **RDS/托管 Kong**：将 `bundled.postgres=false` 或 `gateway.mode=external` 并按要求填外链字段。

网关模式 gateway.mode：**{{ .Values.gateway.mode }}**（nginx | kong | external）

{{- if eq .Values.gateway.mode "nginx" }}
入口 Service：**{{ $fullname }}-gateway**（镜像 nginx）
{{- else if eq .Values.gateway.mode "kong" }}
入口 Service：**{{ $fullname }}-kong-proxy**（内置 Kong declarative）；Admin：**{{ $fullname }}-kong-admin**
{{- else }}
未部署内置网关：**外链 Kong**。请在本集群外将你的 Kong upstream 指向
`{{ $fullname }}-auth/rest/realtime` 等 ClusterIP，并填好 `gateway.externalPublicUrl`
与 `{{ $fullname }}-runtime` 中的密钥。
{{- end }}

Postgres：bundled.postgres={{ .Values.bundled.postgres }}
{{- if .Values.bundled.postgres }}
子 chart：**Release 名后缀 `-postgresql`**。`bundledDb.composeDbRoles=true` 时连接用户对齐 compose（auth/supabase_auth_admin、rest/authenticator、realtime/supabase_admin），依赖 **supabase/postgres** 镜像已初始化角色；若仅用单用户库请关掉 composeDbRoles。
{{- else }}
使用 **externalDatabase.host / port / user / password / dbName**（模板拼 postgres URL）；Realtime 特例见 README。
{{- end }}
